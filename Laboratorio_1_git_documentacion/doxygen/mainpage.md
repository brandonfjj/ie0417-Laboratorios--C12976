# LevelDB — Documentación generada con Doxygen

Este sitio contiene la documentación técnica de la API de **LevelDB**, un motor
de almacenamiento clave-valor embebido desarrollado por Google, generada como
parte del Laboratorio 1 (IE0417).

## Sobre el proyecto original

LevelDB implementa un árbol LSM (Log-Structured Merge-Tree) que ofrece
lectura y escritura ordenada de pares clave-valor, snapshots, e iteración
eficiente sobre rangos de claves.
