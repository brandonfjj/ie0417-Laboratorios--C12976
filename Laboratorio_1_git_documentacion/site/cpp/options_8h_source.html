171  // If true, the write will be flushed from the operating system
172  // buffer cache (by calling WritableFile::Sync()) before the write
173  // is considered complete. If this flag is true, writes will be
174  // slower.
175  //
176  // If this flag is false, and the machine crashes, some recent
177  // writes may be lost. Note that if it is just the process that
178  // crashes (i.e., the machine does not reboot), no writes will be
179  // lost even if sync==false.
180  //
181  // In other words, a DB write with sync==false has similar
182  // crash semantics as the "write()" system call. A DB write
183  // with sync==true has similar crash semantics to a "write()"
184  // system call followed by "fsync()".
185  bool sync = false;
